# SS03 玩家分组政策（2026-08 版）

> 适用游戏：SS03 · 数据表：`slot-machine.public.fct_bet_orders`
> 生效变更：**2026-08-03 16:00 PDT**（= 2026-08-03 23:00 UTC）分组准则由「注单 partition_ab」切换为「user_id 尾号静态分组」。
> 本文为唯一分组口径索引，取数/分析/报告统一引用。代码口径：`jobs/ss03_analysis/ss03_grouping.py`（`GROUP_CASE` / `BASE_FILTER`）。

---

## 0. 一句话

SS03 分组有**切换点**：**切换后**按 `user_id` 尾号静态分 4 组（Default/AB_TEST_A/AB_TEST_B/AI）；**切换前**按注单 `partition_ab[0]`（ab_group_id）映射。分析任何 SS03 数据都要先判断落在切换前/后。

---

## 1. 切换时间点

新准则自**美西 PDT 2026-08-03 16:00** 起生效，三时区等价：

| 时区 | 时间 |
|---|---|
| 美西 PDT | 2026-08-03 16:00 |
| UTC | 2026-08-03 23:00 |
| 北京 | 2026-08-04 07:00 |

> SQL 直接用注单 `created_at`(UTC) 与 `'2026-08-03 23:00:00'` 比较，无需时区转换。

## 2. 新准则（切换点之后）—— user_id 尾号静态分组

按 `MOD(user_id, 10)` 静态分组：

| 组 | 尾号 | 流量占比 |
|---|---|---|
| **Default** | 0、1、2、3 | 40% |
| **AB_TEST_A**（TestA） | 4、5 | 20% |
| **AB_TEST_B**（TestB） | 6、7 | 20% |
| **AI** | 8、9 | 20% |

> **静态**：分组由 user_id 决定，每个玩家永远只属于一组，不随时间/设备/会话变化，也不存在同一人同天跨组。
> **可验证**：各组人数之和应严格 == 总去重人数（分流是否干净）。

## 3. 旧准则（切换点之前）—— 按注单 partition_ab[0]

| 组 | ab_group_id |
|---|---|
| AI | `jojpin-9mokha-rexQug` |
| AB_TEST_A | `4f1a46ca-7baa-4452-9a40-ef21d9b33b57`（math `normal_zero_95_kai`, 95%） |
| AB_TEST_B | `4a04df21-c749-4808-8e55-3a0b74c084d2`（math `normal_Zero_BG97_Saitekika_BGadj`, 97%） |
| Default | 其余全部 |

> **特点**：分组跟着注单走，同一玩家同一天可能出现在多个组里。
> ⚠ **A/B 映射待最终确认**：本表采用 A=`4f1a46ca`、B=`4a04df21`（与 2026-08-17 更正、已重命名的 S3 文件夹一致）。用户所给 SQL 片段里 A/B 与此**相反**，属消息内部不一致；此处以准则文本表为准。仅影响切换前数据。

## 4. 权威判定 SQL

```sql
CASE
  WHEN created_at >= '2026-08-03 23:00:00' THEN   -- UTC, = 08-03 16:00 PDT 切换
    CASE
      WHEN MOD(user_id, 10) IN (0,1,2,3) THEN 'Default'
      WHEN MOD(user_id, 10) IN (4,5)     THEN 'AB_TEST_A'
      WHEN MOD(user_id, 10) IN (6,7)     THEN 'AB_TEST_B'
      ELSE 'AI'                                    -- 8,9
    END
  WHEN partition_ab[0]::varchar = 'jojpin-9mokha-rexQug'                  THEN 'AI'
  WHEN partition_ab[0]::varchar = '4f1a46ca-7baa-4452-9a40-ef21d9b33b57' THEN 'AB_TEST_A'
  WHEN partition_ab[0]::varchar = '4a04df21-c749-4808-8e55-3a0b74c084d2' THEN 'AB_TEST_B'
  ELSE 'Default'
END AS ai_group
```

通用清洗（BASE_FILTER）：
```sql
game_id='SS03' AND currency_type='CNY' AND status='COMPLETED'
AND op_code NOT IN ('B26','TST','TSB','TSO')
```

## 5. 关键口径说明

- **尾号 = `MOD(user_id,10)`**（十进制末位），静态、可复算、终身不变；{0-3}=40%、{4,5}/{6,7}/{8,9} 各 20%。
- **切换点即分界**：`created_at >= 2026-08-03 23:00 UTC` 用尾号；此前用 `partition_ab[0]`。近期(如 08-07 起)数据**全在切换后 → 必须用尾号**，不能再用 partition_ab（易错点）。
- `partition_ab` 是 SUPER 数组，取首元素用 `partition_ab[0]::varchar`。
- `bet_amount>0` = BASE（有效投注）；`bet_type='FREE'` 为免费轮（bet=0，含 FG 赔付）。RTP=SUM(actual_payout)/SUM(bet_amount)。
