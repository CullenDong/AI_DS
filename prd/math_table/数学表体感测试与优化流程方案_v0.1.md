# 数学表体感测试与优化流程方案 · v0.1

> 本方案旨在将"体感"（game feel）由经验性、主观性的设计判断，转化为**可操作化、可测量、可验收**的标准流程。方法论上采用"构念—操作化—测量—验证"（construct → operationalization → measurement → validation）范式：将抽象的体感构念操作化为可计算的数学指标，经数学设计实现，再通过盲测收集主观量表数据并与客观埋点指标交叉验证，最终以线上 A/B 实验确认其业务效度。全流程包含五个阶段：市场定位、体感需求操作化、数学设计、盲测验证、迭代与上线。

## 流程总览

```
① 市场调研 · 用户画像 · 产品定位
        │  产出：目标受众界定 + 产品定位
        ▼
② 体感需求操作化（构念定义 + 数学指标 + 目标区间）
        │  产出：分受众「体感需求操作化表」
        ▼
③ 数学设计（CBO / Esscher / 蒙特卡洛模拟，满足体感约束 + RTP 护栏）
        │  产出：候选数学表 + 设计说明（各表对应的体感构念）
        ▼
④ 盲测验证（跨职能受试 · 标准化投注协议 · 主观量表 + 客观埋点）
        │  产出：主观评分 + 客观指标 + 主客观效度分析
        ▼
⑤ 判定 · 迭代 · 上线真实 A/B（衔接 ab-experiment-design）
```

![数学表体感测试与优化流程图](data/output/math_table/feel_test_flow.png)

各阶段产出构成下一阶段的输入；任一阶段未达标则回退至上游修正。盲测验证定位为**上线真实 A/B 前的低成本前置筛选与量表校准环节**，不替代线上因果验证。

## 第一步 · 市场调研 · 用户画像 · 产品定位

**目的**：明确目标受众与产品定位，为后续体感需求提供推导锚点，避免脱离受众与定位的无约束调参。

1. **市场调研**：梳理目标市场同类产品的机制特征（命中率、波动等级、免费游戏触发率、封顶倍数、是否开放购买免费游戏）、主流 RTP 区间，以及玩家反馈的关注维度（爆发性、耐玩性、挫败感等），据此建立"竞品体感基线"作为横向参照系。
2. **用户画像分析**：基于现有数据对玩家分层（复用 HMM 生命周期状态 T1/S1/S2/S3、日龄分层 new/beginner/old、投注额分层 casual/core/whale），刻画各层的典型投注额、单次会话发数与时长、免费游戏接触频率、流失特征等，作为体感需求的服务对象。
3. **产品定位确立**：以定位陈述加波动取向的形式明确产品调性，示例：
   - **低波动·高命中型**：以高命中率与长陪伴时长服务低额休闲群体；
   - **高波动·高爆发型**：以高倍数、强波动服务高价值群体的爆发性需求；
   - **均衡型**：基础游戏稳定、免费游戏提供正向惊喜。

> 产出物：**《目标受众界定与产品定位报告》**。定位须与竞品基线量化对齐（例：定位为"耐玩性优于竞品"，则命中率、破产发数等指标须优于竞品基线）。

## 第二步 · 体感需求的操作化（核心）

将"易中小奖""低投注玩家可获得更长游玩时长""大奖接触频率更高"等**抽象体感构念**，逐条操作化为**可计算的数学指标 + 目标区间 + 数据来源**。此步骤是全流程的方法论关键：未经操作化的构念既无法指导设计，亦无法用于验收。

### 2.1 体感构念操作化对照表

| 体感构念 | 受众感知描述 | 操作化数学指标 | 数据来源 |
|---|---|---|---|
| **中小奖密度** | 小额奖励频繁、无长时间空窗 | 基础游戏命中率 = base_hits/base_n；0–2x 赔付轮占比 | `bet_type=BASE` |
| **低额留存时长** | 低投注下可维持较长游玩 | 给定预算的期望存活发数 ≈ 预算 /（bet × (1−BG_RTP)）；低额段中位会话发数与时长 | 模拟 + 实测 |
| **大奖接触频率** | 大额奖励的可达性较高 | P(单次赔付 ≥ Nx)；每百发出现 ≥ Nx 的次数；首次达到 ≥20x 的中位发数 | payout 分布 |
| **大奖强度** | 峰值奖励足够高 | 最大倍数、p99 单发赔付、免费游戏单轮最大赔付 | Max Values sheet |
| **空窗容忍度** | 连续未中奖的持续长度受控 | 连续未中（dry streak）长度 p90/p99；命中间隔中位 | 序列 |
| **免费游戏预期** | 免费游戏触发具备可预期性 | 触发率、免费游戏触发间隔中位、near-miss（差一 scatter）率 | `root_spin_id` |
| **节奏与波动** | 收益轨迹具备起伏与张力 | 余额轨迹波动标准差、盈利面时间占比、Volatility Index | balance 轨迹 / Summary |
| **资金损耗速率** | 本金消耗速率适中 | 每百发净损（缩尾均值 + 中位）、破产发数分布 | net |
| **免费游戏陪伴度** | 免费游戏具备一定持续时长 | 免费游戏平均 run 长度、Retrigger%、免费游戏 RTP 贡献占比 | Adaption/Summary |

> 说明：右侧指标多数在设计方 Excel 中已有对应字段（Hit%、Volatility Index、Free Trigger%、Top 5 wins、Multiplier Stats、Max BG Multiplier、SD/Skewness/Kurtosis），可直接作为理论锚点；线上实测则基于 `fct_bet_orders`（`bet_type` / `actual_payout` / `root_spin_id`）复算。

### 2.2 分受众「体感需求操作化表」（模板）

每一目标受众对应一张表，将产品定位分解为 3–6 条**附带目标区间与优先级**的体感需求。以"低波动·高命中"定位为例：

| 目标受众 | 体感需求 | 操作化指标 | 目标区间 | 优先级 |
|---|---|---|---|---|
| 低额休闲（casual/new） | 中小奖密度充分 | 基础游戏命中率 | ≥ 35% | P0 |
| 低额休闲 | 低额留存时长充分 | 100 币预算中位存活发数 | ≥ 150 发 | P0 |
| 低额休闲 | 空窗容忍度受控 | dry streak p90 | ≤ 12 发 | P1 |
| 核心（core） | 中奖接触频率适中 | 每百发 ≥10x 次数 | ≥ 1.5 次 | P1 |
| 高价值（whale） | 大奖强度充分 | 最大倍数 / p99 单发 | ≥ 目标封顶 | P1 |
| 高价值 | 免费游戏预期合理 | 触发率 | 落在 [下限, 上限] | P2 |

**规范要求**：① 每条需求须可计算、可验收；② 目标以区间而非单点表述，为数学设计保留可行域；③ 标注优先级（P0 硬约束 / P1 重要 / P2 加分），需求冲突时按优先级取舍；④ 全表受 **RTP 护栏**（如 95%±0.5pp）约束——体感需求本质是在固定 RTP 预算内对赔付结构的再分配，而非无约束地提升赔付。

## 第三步 · 数学设计（体感约束下的赔付结构优化）

数学组依据《体感需求操作化表》设计**一款或多款**候选数学表：

- 在 RTP 护栏约束下，通过 payout 分布调整（Esscher 指数倾斜以压缩或抬升特定倍数区间）、命中率与触发率调节、基础游戏/免费游戏预算再分配，逐项逼近各体感目标区间。
- **每款表对应一组体感假设**：明确其主要优化的构念（例："表 A：高命中、低波动，主攻低额留存时长"；"表 B：抬升大奖尾部并开放购买免费游戏，主攻高价值大奖强度"），使多表之间构成对照。
- 每款表先经**蒙特卡洛模拟**：输出 2.1 全部指标与目标区间的达标情况及 RTP 收敛结果，形成"设计侧自检表"，理论达标者方进入盲测。
- 记录设计改动点（所调整的 payout 区间、命中率、触发率），供后续实测 RTP 偏差归因复用。

> 产出物：**候选数学表 ×N 及各表《设计说明》**（主攻构念、关键改动、模拟自检指标）。

## 第四步 · 盲测验证（核心）

在受试者不知晓当前数学表身份与设计意图的条件下进行真实体验并评分，将抽象体感转化为量表数据，同时采集客观埋点指标进行交叉验证。

### 4.1 盲测设计原则

- **盲法**：受试者不知晓当前数学表编号及其设计意图，以消除先验预期偏差；数学表呈现顺序随机化并做配平（counterbalance），以抵消学习效应与疲劳效应。
- **跨职能、大样本**：受试者涵盖 PM 组、数学组、测试组等多职能同事，样本量越大则量表评分越稳健。**须注意**：盲测样本量通常有限，故结论为定性/方向性，仅作真实 A/B 前的筛选，不构成最终因果判定。
- **环境统一**：采用沙盒环境与统一虚拟币、统一起始余额、统一客户端，以排除真实资金差异对体感的干扰。

### 4.2 标准化投注协议（控制变量的关键）

投注行为本身显著影响体感（同一数学表下，密集购买免费游戏与仅进行基础游戏的感知存在系统性差异）。因此须限定投注行为，将测试划分为若干**标准化投注剖面**，每一剖面的规定动作一致，并**按剖面分别汇总体感**：

| 剖面 | 对应受众 | 投注额 | 规定动作 | 终止条件 |
|---|---|---|---|---|
| **P1 低额休闲** | 新/低投注 | 最小档 | 仅进行基础游戏，不购买免费游戏 | 固定 200 发 或 15 分钟 |
| **P2 中额核心** | 核心 | 中档（均值档） | 常规游玩，自然触发免费游戏 | 固定 200 发 或 15 分钟 |
| **P3 高额追奖** | 高价值/追奖 | 高档 或 购买免费游戏 | 主动追求大奖 / 购买免费游戏 | 固定预算耗尽 或 200 发 |

- 每位受试者对每张数学表**完成指定剖面**（全部或分配），起始余额固定，剖面顺序配平。
- 剖面与第一步的用户画像、第二步的体感需求逐一对应，使体感目标可按受众分别验收，避免跨受众混淆。

### 4.3 主观量表设计（体感构念的评分化）

每张数学表 × 每一剖面完成后，受试者填写**体感量表**。以固定题项将抽象感知锚定为分数：

| # | 量表题项 | 量表刻度 | 对应操作化指标（用于效度验证） |
|---|---|---|---|
| Q1 | 中小奖出现频率 | 过低 1 — 适中 3 — 过高 5 | 基础游戏命中率 |
| Q2 | 大奖的可达性与预期 | 不可达 1 — 高预期 5 | 每百发 ≥Nx 次数、触发率 |
| Q3 | 连续未中的挫败感 | 强挫败 1 — 无挫败 5 | dry streak p90 |
| Q4 | 本金消耗速率的感知 | 过快 1 — 适中 3 — 过慢 5 | 每百发净损（缩尾+中位） |
| Q5 | 游戏节奏与刺激度 | 平淡 1 — 强烈 5 | 余额波动标准差、Volatility Index |
| Q6 | 免费游戏的满足度 | 失望 1 — 满足 5 | 免费游戏 run 长度、贡献占比 |
| Q7 | **持续游玩意愿** | 无意愿 1 — 强意愿 5 | （综合指标，对标留存）|
| Q8 | 开放式主观描述 | 文本 | 定性归因 |

- **双极量表**（Q1/Q4：过低↔过高，3=适中）用于存在"过犹不及"的构念；**满意度量表**（Q2/Q3/Q6/Q7：单调递增）用于正向构念。
- 各剖面固定同一题库，以支持跨表横向比较及均值/分布统计。

### 4.4 客观指标埋点（客观测量层）

盲测期间**逐发记录**投注额、赔付、bet_type、倍数、余额、时间戳。测试结束后自动计算每（表×剖面）客观指标：基础游戏命中率、首次大奖发数、最长 dry streak、结束余额、≥Nx 次数、免费游戏触发数与 run 长度、余额轨迹等。**客观指标构成体感的客观测量层，主观量表构成主观测量层，二者交叉验证。**

### 4.5 盲测执行清单

1. 数学组交付候选表及各表设计说明（主攻构念）；数据组配置埋点与计分脚本。
2. 测试组搭建沙盒环境、下发剖面协议与量表、随机化并配平数学表顺序。
3. 招募跨职能受试者（PM/数学/测试），统一培训剖面规定动作。
4. 受试者按协议执行（表×剖面），系统逐发埋点，各剖面后填写量表。
5. 回收主观评分数据与客观埋点日志。

## 第五步 · 判定 · 迭代 · 上线真实 A/B

**判定准则**（按数学表、分剖面）：

1. **客观达标**：2.1 各指标落入第二步目标区间（容差范围内）。
2. **主观达标**：目标体感构念的量表均分达阈（如 P0 构念 ≥4/5），且 Q7 持续游玩意愿不低于对照/基线。
3. **主客观效度**：主观评分与对应客观指标方向一致（用于验证 2.1 操作化映射的效度；若不一致，则修正操作化映射或量表题项）。
4. **RTP 护栏**：模拟/实测 RTP 收敛于护栏区间内。

**结论与动作**：

- 达标数学表 → **进入线上真实同期 A/B 实验**（依 `ab-experiment-design` skill：user_id 尾号分流、H1/H2/H3 假设、主指标 + 护栏指标、缩尾均值 + 中位双口径、ITT 分析），以真实留存与投注行为验证体感是否转化为业务效度。
- 未达标数学表 → 依据"未满足的体感构念 + 主客观偏差点"回退至**第三步**重新设计，或回退至**第二步**修正目标区间。
- 每轮迭代将"体感构念—数学指标"的**操作化映射校准结果**沉淀入对照表（2.1），以持续提升映射效度。

## 开放问题

- **OQ-1 盲测介质**：真实资金 vs 虚拟币/沙盒（建议采用沙盒，兼顾成本控制与批量可行性）。
- **OQ-2 样本量**：受试者数量 N，及每（表×剖面）的最小有效样本量；低于阈值者仅作定性结论。
- **OQ-3 盲测工具**：是否需专用盲测客户端/后台（随机发放数学表、自动埋点、内嵌量表）。
- **OQ-4 量表规格**：5 点 vs 7 点刻度；双极题与满意度题的最终题库。
- **OQ-5 映射效度校准**：体感构念—数学指标映射需多轮盲测积累方趋稳定，首轮容忍偏差。
- **OQ-6 结论仲裁边界**：盲测为设计侧前置筛选，真实留存/LTV 仍以线上 A/B 为准，二者结论不一致时的仲裁规则。
