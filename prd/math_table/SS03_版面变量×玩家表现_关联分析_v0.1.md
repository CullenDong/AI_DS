# SS03 剧本版面变量 × 玩家行为 · 彻底关联分析 · v0.2（本地稿，未上传）

> 问题：每一个**玩家行为**（投注次数/总额/底注/时长/留存）分别最受哪些**数学表版面指标**影响？数据 = S3 增强表 `SS03_mathtable_split`（2026-06-09~09-14，98 天，CNY 标准口径，映射 100%）。单位 = 玩家×天（≥20 发，119,321 条）。留存 = 当天有投注即活跃、按天算、右截断置空。

## 0. 变量与命名（先说清楚每个是什么）

**玩家行为（Y，被解释；绝不作解释变量）**

| 名称 | 定义 |
|---|---|
| 投注次数 `num_bets` | BASE 付费发数（不含免费游戏 FG） |
| 投注总额 `total_bet` | 当天 Σ 投注额 |
| 投注底注 `bet_level` | 每发投注额（档位 0.5~500） |
| 游玩时长 `dur_min` | 当天首末发时间跨度（分钟） |
| 留存 `ret1/ret7` | 次日 / 7 日是否回访 |

**数学表版面指标（X，解释变量；从 script_id 映射回剧本库打到每发）**

| 名称 | 定义 |
|---|---|
| **平均每发赢的倍数** | 玩家每发平均赢多少倍（= `reelset_payout/20`，20=1 倍下注）。**本质=玩家的手气/回报**（≈0.7 即基础游戏每发平均回报 70%） |
| **赢≥5倍率** | 赢到 ≥5 倍下注的发数占比（即 `reelset_payout≥100`）。〔注：之前误标为"大奖≥100x"，实为 ≥5 倍〕 |
| **免费游戏触发率** | 触发免费游戏的发数占比 |
| **连消步数** | 级联（cascade）步数均值 |
| **wild中奖率** / **golden中奖率** | wild / golden 参与到中奖的发数占比 |
| **平均scatter数** | 每发 scatter 数均值 |
| **差一个触发率** | 2 个 scatter（差一个触发免费游戏）的发数占比 |

> 关键提醒：**"平均每发赢的倍数"其实就是"玩家赢了多少"**（手气/回报），不是一个可独立设计的结构特征——它和玩家行为相关，某种程度上是预期内的（赢得多→玩得多）。真正的**结构设计特征**是下面的 scatter/wild/golden/连消/差一个触发。

## 1. 方法学（为什么这版可信）

前一版相关系数被两个假象污染，本版修掉：
1. **低投注→率不稳假象**：版面指标是"每发率"，投注少的玩家率飘、挤在极端档，与投注次数虚高相关。→ 限 ≥20 发；参与类指标改用**开局前 20 发经历**预测整段行为（早经历在前、行为在后，破除互为因果）。
2. **参与度混淆留存**：玩得多本就更留存。→ 留存回归**控住 log(投注次数)**，只看版面独立作用。
3. **底注**：另用**事件级同玩家前后对照**（上一发结果→这一发底注）。

统一用**标准化回归系数 β**（每 +1 标准差版面指标 → 行为的标准差变化，已控其它版面指标）。**β 越接近 0 = 影响越弱。**（β 与单位无关，改名/换算不影响数值。）

## 2. 逐玩家行为结果

### 2.1 参与类（开局前 20 发经历 → 整段行为，标准化 β）

| 版面指标 | 投注次数 | 投注总额 | 游玩时长 |
|---|---:|---:|---:|
| **平均每发赢的倍数** | **+0.089** | **+0.076** | +0.066 |
| **免费游戏触发率** | +0.056 | +0.058 | **+0.085** |
| 赢≥5倍率 | +0.040 | +0.026 | +0.024 |
| 连消步数 | +0.007 | +0.016 | +0.033 |
| golden中奖率 | +0.012 | +0.007 | −0.000 |
| wild中奖率 | −0.034 | −0.025 | −0.014 |
| 差一个触发率 | −0.007 | −0.014 | −0.003 |
| 平均scatter数 | −0.004 | −0.000 | −0.015 |

→ **投注次数/总额**：`平均每发赢的倍数` > `免费游戏触发率` > `赢≥5倍率`（早期赢得越多/越早摸到免费游戏，后面投得略多）。**游玩时长**：`免费游戏触发率` 最强。**但都很弱（β≤0.09）。**

### 2.2 投注底注

- **日级（开局经历 → 当天底注）**：`免费游戏触发率`+0.030、`平均每发赢的倍数`+0.024、`连消步数`+0.019 —— 几乎无影响。
- **事件级（同玩家，上一发结果 → 这一发底注）**：

| 上一发 | 玩家内底注均 | 相对没中 |
|---|---:|---:|
| 没中 | 2.485 | — |
| 赢 <5 倍 | 2.495 | +0% |
| 赢 5-50 倍 | 2.645 | +6% |
| **赢 ≥50 倍** | **3.829** | **+54%** |

→ **底注唯一的强信号是"赢一次大的（≥50 倍）→ 下一发立刻 +54%"**（house-money，即时反应）；日级/累积层面版面几乎不影响底注。

### 2.3 留存（全天版面经历 → 次留/7 留，logistic 标准化 β，已控参与度）

| 变量 | 留存 D1 | 留存 D7 |
|---|---:|---:|
| 参与度 log(投注次数)〔非版面，主导〕 | **+0.874** | **+0.797** |
| **平均每发赢的倍数** | **+0.120** | −0.035 |
| 赢≥5倍率 | **−0.086** | **−0.112** |
| golden中奖率 | −0.081 | −0.083 |
| 连消步数 | +0.055 | +0.067 |
| wild中奖率 | −0.044 | −0.063 |
| 差一个触发率 | −0.034 | −0.060 |
| 免费游戏触发率 | +0.033 | −0.018 |
| 平均scatter数 | ≈0 | ≈0 |

→ 留存**压倒性由参与度决定**（β≈0.85，属玩家行为、非版面）。版面里：`平均每发赢的倍数` 对 **D1 微正**（+0.12），但 `赢≥5倍率` 反而**微负**（−0.09，兑现离场）；到 **D7** 赢的倍数转中性、赢≥5倍仍负——版面对中长期留存基本洗没。

## 3. 结构设计特征（差一个触发 / scatter / wild中奖 / golden中奖）

对**所有**玩家行为的 β 都在 **±0.09** 内、且方向不稳。**证据不支持"靠加 wild/golden/差一个触发/scatter 去影响玩家行为"**——它们看着热闹，实际不驱动投注也不驱动留存。

## 4. 结论（诚实版）

1. **数学表版面对玩家行为的影响整体很弱**（控住假象后标准化 β 多 ≤0.12）。
2. **唯一有一致（弱）相关的是"玩家赢了多少"**（平均每发赢的倍数 / 免费游戏触发 / 赢≥5倍）→ 略微拉高投注/时长；其中 `免费游戏触发率` 对时长最强。**但这本质是"赢得多→玩得多"，接近预期、不是可独立设计的结构杠杆。**
3. **底注唯一强信号是事件级"赢一次大的 → 下一发 +54%"**（即时 house-money）。
4. **留存**：参与度主导；版面里赢得多对 D1 微正、赢≥5倍微负（兑现离场），D7 基本无版面效应。
5. **结构设计特征（差一个触发/scatter/wild中奖/golden中奖）对任何玩家行为都近乎无作用**——最硬的结论。

**运营含义**：能影响玩家行为的，是"**让玩家实际赢到、早点摸到免费游戏**"（且防赢大后兑现离场），而不是在盘面堆 wild/golden/差一个触发这些结构花样。
