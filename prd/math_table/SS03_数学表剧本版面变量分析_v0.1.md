# SS03 数学表 · 剧本版面变量分析报告 · v0.1

> 用每一发 spin 映射回剧本库拿到的**版面变量**（scatter 数、级联 steps、wild/golden 数量与使用、剧本赔付桶），按数学表刻画各表的"版面性格"。数据 = S3 增强表 `SS03_mathtable_split`（2026-06-09 ~ 09-14，98 天全量，CNY 标准口径），映射命中 100%。查表逻辑见 `docs/SS03_剧本版面查表逻辑_v0.1.md`。

## 摘要：五类版面性格

| 版面分型 | 代表表 | 特征 |
|---|---|---|
| **基准型** | `zero_95_kai` / `zero` / `zero93kai` | scatter/near-miss 高、赔付集中"零 + 中额(6-20)"，标准波动 |
| **抬中额型（CBO）** | `BGTR95_Saitekika_v3` / `BGTR97_v2` | wild 用得多、级联多、**赔付从 6-20 搬到 21-100**、near-miss 更低 |
| **高命中小额型** | `BG97_Saitekika` | 级联/wild 使用率极高、**35% 落 1-5 小奖**、零赔付率仅 35% |
| **低波动数字型** | `shi/ni/san/go/roku/ichi` | scatter/near-miss 最低、golden 多但极少参与、FG 触发率偏高 |
| **暗保底型** | `kakuteiA/B/C` | **scatter 恒=3、FG 100% 触发、无级联无 wild 使用**（强制免费游戏） |

## 一、数据与口径

- 源：`s3://bituslabs-team-ai/SS03_mathtable_split/table=<表>/dt=<日>/part.parquet`（15 表 × 98 天，2.95GB）。
- 口径：`game_id='SS03' AND status='COMPLETED' AND currency_type='CNY' AND op_code NOT IN (...)`；北京日。
- 版面变量来自 `snapshot.script_id → script_id_map.json → catalog`，逐发打标（命中 100%）。
- BASE（基础游戏）与 FREE（免费游戏）分开看——FREE 的版面性质完全不同。

## 二、版面变量释义

| 变量 | 含义 |
|---|---|
| `scatter_count` | 版面上 scatter(201) 数；=3 触发免费游戏，=2 为 near-miss（差一个触发） |
| `steps` | 级联（cascade）步数，越大连消越长 |
| `total_wild` / `used_wild` | 版面 wild(202) 数 / 参与中奖的 wild 数 |
| `total_golden` / `used_golden` | 版面 golden(100-108) 数 / 参与中奖的 golden 数 |
| `free_triggered` | 免费触发（0=无，10/12/14…=触发） |
| `reelset_payout` / `payout_bucket` | 该剧本总赔付倍数 / 分桶（0 / 1-5 / 6-20 / 21-100 / 101-500 / 500+） |

## 五、解读

**1) 基准三兄弟本质同一套**：`zero_95_kai` / `zero` / `zero93kai` 各版面指标几乎一致（scatter≈0.87、near-miss≈28.6%、赔付桶完全重合）——它们用同一剧本池，差异在 RTP 缩放而非版面。

**2) BGTR 系（CBO 抬中额）**：相对基准 —— **near-miss 更低（23.6% vs 28.6%）、wild 用得更多（29% vs 23%）、级联更长**；最关键是**赔付从 6-20 搬到 21-100**（6-20 从 11%→5.3%，21-100 从 8%→17%）。即 CBO 把"中小奖"重新分配成"中额奖"，体感上"中奖更值钱但触发略稀"，FG 触发率也压低了（0.30% vs 0.46%）。

**3) BG97_Saitekika（高命中小额）**：最独特 —— **零赔付率只有 35%（其余表 ~70%）**、35% 落在 1-5 小奖、级联均值 0.90（最高）、**wild 使用率 60%**。这是"几乎每把都中点小的、靠 wild+连消堆命中感"的表。

**4) 数字表系（shi/ni/san/go/roku/ichi，低波动）**：scatter/near-miss 全场最低（~17%）、**golden 多（均值~2）但几乎不参与中奖（用率 2.5%）**、FG 触发率偏高（0.7-1.0%）、赔付集中 6-20、几乎无 21-100。低起伏、靠免费游戏给惊喜。

**5) 暗保底（kakuteiA/B/C）**：**scatter 恒=3、FG 100% 触发、steps=0、wild 零使用** —— 就是强制发免费游戏的保底表，版面无悬念。

**6) FREE（免费游戏）**：大奖集中在 FREE —— 基准/BGTR/BG97 系 FREE 里 **≥100 倍占比 ~20%**（BASE 仅 ~3%）；而 kakutei 系 FREE 大奖占比低（~5%）、wild 使用重、更"细水长流"；数字表系 FREE 大奖占比也偏低（7-9%）。

## 六、结论与用途

- **版面变量能量化区分各表设计取向**：基准（标准波动）／BGTR（抬中额、CBO）／BG97（高命中小额）／数字表（低波动）／kakutei（暗保底）——五类性格用 scatter/near-miss/wild使用/赔付桶就能分开。
- **near-miss 密度**（scatter=2）是重要体感量：基准 ~29%、BGTR ~24%、数字表 ~17%——"差一点触发"的频率差异明显，可对接体感测试。
- **golden 多但少用**（数字表尤甚）：golden 更多是版面点缀/期待感，实际转化中奖少，是潜在的"看着热闹、实则不出"的体感来源。
