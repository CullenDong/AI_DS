# FM01 捕鱼 · 动态 RTP v3（分鱼种）总结与未来展望

> 对象：`DYNAMIC_RTP_V3`（动态调控 RTP · 分鱼种，新版）vs `DEFAULT_FALLBACK`（原始对照）。
> 数据由数据组从 `transform-agfish-game.public.bullet` 统计，**按月分段**（v3 上线北京日 2026-06-10，连续跑到最新）；口径见 §二 前注。历史结论引自研究侧 6.9–6.24 成稿。

## 摘要（结论速览）

- **v3 定位随参数下调而变（按月看很清楚）**：v3 实测整组 RTP **6 月 97.40% → 7 月 97.50%（均高于对照）→ 8 月骤降到 95.95%（首次低于对照 96.90%）→ 9 月 95.74%（部分）**。参数下调拐点在 7 月末/8 月初。
- **但留存优势全程稳定、不受 RTP 下调影响**：v3−对照 D1 逐月 **+3.4 / +3.5 / +3.8pp**——**放水降了，留存优势反而略升**。坐实"留存由分鱼种 + 冷启动的**动态节奏**驱动，而非整体 RTP 高低"。首杀轮次全程更快（中位 7 轮 vs 对照 9 轮）。
- **分层看（关键）**：v3 的增益**主要来自新玩家的冷启动加成**——T1 首日 / 日龄 0-3 天，v3 RTP 更高（`rtp_th` 中位 1.16~1.18 vs 对照 0.965）、留存 D1 +2~3pp；而对**核心活跃（S2）/ 资深玩家，v3 无收益甚至略负**。→ 应**按玩家分层做不同 RTP 曲线**。
- **鲸鱼偏斜极大，务必看中位/均99**：典型玩家其实很轻——人均发**中位仅 ~280，均值却 ~4,000**（被鲸鱼拉高十几倍）；人均累投中位 ~450 vs 均值 ~1.6 万。本文所有均值类指标都给「**中位 / 均值 / 0-99%缩尾均值**」三视图。
- **待解**：v3 冷启动把理论 `rtp_th` 抬到中位 1.06~1.18，而实测整组 RTP 落在 96% 附近——**理论 ↔ 实测 RTP 存在 gap**，与数学表报告同一课题，需归因与校准。

## 一、动态 RTP v3 是什么（设计初衷）

动态 RTP：系统按**玩家 × 鱼种 × 生涯阶段**动态调整每发子弹下发的**理论 RTP（`rtp_th`）**，而非全体一张静态放水表。迭代路线 v1 → v2（引入分鱼种）→ **v3（分鱼种新版）**。核心设计意图：

- **冷启动加成**：生涯前期把 `rtp_th` 抬高（研究侧观测前 ~200 注 ~1.6），**加速早期击杀/中奖反馈**、降低新玩家"打半天不中"的劝退；之后**逐步回落**到目标附近。
- **分鱼种调控**：不同鱼种（价值/难度）走不同 RTP 曲线，让体验更贴合"该不该让这条鱼被打中"。
- **目标**：在**贴近目标 RTP（0.96）**的总放水约束下，用节奏（何时给、给哪条鱼）换取更好的留存与参与，而不是单纯抬高整体 RTP。

**读数——v3 的收益并不均匀，主要集中在新玩家 / 小额玩家：**

- **T1 首日 / new（0-3 天）：v3 明显最优（冷启动兑现）**。v3 对首日玩家 **RTP 更高**（T1 98.10 vs 96.95、new 97.05 vs 96.27），**`rtp_th` 中位 1.16~1.18 vs 对照 0.965**（冷启动加成只加给新玩家），人均发中位 +40~50%、**留存 D1 +2~3pp**（T1 11.0 vs 9.0、new 16.2 vs 13.4）。这是 v3 总体留存优势的**主要来源**。

- **S2 核心活跃 / beginner：v3 无收益、甚至略负**。对已高度参与的核心玩家，v3 **人均发中位 3692 vs 4028**、**留存 D3/D7 反而低 3~4pp**（51.7/42.2 vs 55.4/46.4），`rtp_th` 已回到 0.96（无冷启动加成）。
- **按投注额看，同一规律再次复现**：**小额玩家（<1000，占 66%）受益最大**——v3 给他们的 RTP **84.82% vs 71.18%（+13.6pp）**、`rtp_th` 中位 **1.269 vs 0.965**（冷启动加成几乎全给了小额/新玩家），人均发、留存也更高；**中额玩家**留存略好（D1 +2.6pp）；**大额玩家（≥20000，仅 8% 却占 92% 投注）v3 反而略负**——RTP **96.18% < 97.44%**、`rtp_th` 无加成（0.961）、留存 D3/D7 略低。
- **结论**：总体留存增益**主要由新玩家 / 小额玩家的冷启动加成驱动**；v3 本质是**把 RTP 从大额/核心玩家匀给新/小额玩家**（冷启动只加给后者）。对核心/资深/大额玩家 v3 需要**不同的 RTP 曲线**（直接呼应展望 §5.3「一类玩家一条 RTP 曲线」）。

---

## 四、结论

1. **v3 的价值已验证，但落点集中在新玩家**：v3 在**更低放水成本**下（8 月起 RTP 95.95% < 对照 96.90%）拿到**更好留存（D1 +3.4~3.8pp，全程稳定）+ 更快首杀（中位 7 vs 9 轮）**；分层看，增益主要来自 **T1 首日 / 新玩家的冷启动加成**，对核心活跃/资深玩家 v3 无收益甚至略负。
2. **驱动力是"动态节奏"而非"整体放水"**：RTP 从 97.5% 降到 95.95% 穿过对照线后留存优势不降反升，证明分鱼种 + 冷启动的时序调控才是留存增益来源。
3. **务必用中位/均99 读**：投注类指标鲸鱼偏斜极大（人均发中位 ~280 vs 均值 ~4000），典型玩家很轻；均值只反映头部体量。
4. **一个待解课题**：v3 冷启动把理论 `rtp_th` 抬到中位 1.06~1.18，实测整组 RTP 却落在 96%——理论 ↔ 实测 gap 需归因与校准（与数学表报告同一问题）。

## 五、未来展望

### 5.1 dynamic_rtp 扩充应用面至全体玩家，并处理与个性化挽留系统的共存
- 目前 dynamic_rtp 与个性化挽留系统的实现方式相同——都是对**单发子弹的理论命中概率（`rtp_th`）**做调整。两者合并、同时作用于同一玩家时，可能相互干扰、对体验产生负面影响：例如当玩家正处于**高 RTP 阶段、dynamic_rtp 需要下拉 RTP** 时，若个性化挽留系统此刻**介入抬升 RTP**，会导致 dynamic_rtp 随后做**更大幅度的阶段性下拉**，使玩家经历**更长时间的"铁鱼"（打不动/久不中）**体验。
- 因此扩面到全体玩家前，需先设计两套 `rtp_th` 调整的**共存/仲裁规则**：谁优先、如何叠加、阶段性下拉/抬升的幅度与上下限约束，避免两策略"对着干"放大体验波动。

### 5.2 分鱼种调控的精细化
- 现在按鱼种走不同 RTP 曲线，可进一步**按鱼种 × 生涯阶段 × 玩家分层**做多维调控；重点核对高价值鱼种的击杀节奏是否符合设计。

### 5.3 一类玩家一条 RTP 曲线（与 HMM / 日龄 / 投注额分层结合）
- 本报告已证明 v3 收益集中在新玩家、对核心/资深无收益甚至略负——应把冷启动加成**针对性给新玩家/回流玩家**，对核心/资深玩家设计**不同曲线**（甚至不加成、避免抑制）。用 HMM 状态 / 日龄 / 投注额分层做 A/B 验证。

### 5.4 生涯曲线与长期价值监控
- 建立 v3 的**生涯 `rtp_th` / 累积 RTP 曲线**常态监控（冷启动的抬升与回落节奏是否稳定），并补 **LTV / 长期留存（D14/D30）**，确认早期留存增益能否转化为长期价值。
