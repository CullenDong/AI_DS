## 一、口径

- **游戏级整体·逐月**（每 游戏 × 月，全体玩家不分组）：投注用户（当月有实际投注的去重玩家）、总投注额(万)、总GGR(万=投注−payout)、RTP%(含 FG)、人均投注额 / 人均投注次数 / 人均游玩时长(分) 的「中/均/均99」（以**中位**为稳健读数）、D1/D3/D7 留存（当月某北京日活跃玩家 D+N 日仍有该游戏投注，右截断置空）。游玩时长 = 每玩家每活跃日「当日 max−min 时间戳」之和（分，日内活跃代理）。
- 清洗：CNY、剔测试单、slot 取 COMPLETED。数据源：FM01=`bullet`、SS0x=`fct_bet_orders`。
- **注意**：整体轨迹是**描述性**的，含用户增长/买量/季节等混淆；与策略仅作**时间对应**，不作因果归因。

## 二、调控效用归因（能干净归因的：老虎机随机分桶 A/B）

**归因结论——哪个调控带来了什么收益：**

- ◐ **SS06 暗保底 小幅提升**：投注次数 +2~4%、RTP 更贴目标、7 月留存略正——**小幅正向**，主要体现在体验兜底/RTP 托底（8 月留存转弱，持续性待更长窗口）。
- ⚠ **FM01 动态RTP / 风控 / 挽留无法干净归因**：非随机分组、选择偏差大，本报告不下因果结论，只提供 §三 整体时间轴；干净因果需随机 holdout（研究侧 SageMaker A/B）。

## 八、跨游戏结论与建议

1. **整体轨迹里两处最亮**：**SS03 上线+AI/暗保底期留存翻倍爬坡（D1 11.9→18.9）**、**FM01 三机制齐全的 8 月留存跳升（D1 27→33）**；两者都处于"多项调控密集上线"期，但也叠加了游戏成长/买量，**只能作时间相关、不能单归因**。
2. **投注维度**：SS03 投注额中位随 CBO 新表（BGTR 系）7-9 月上行，是相对干净的信号（有专项同期对比佐证）；FM01 投注/GGR 整体上行含用户规模。
3. **鲸鱼是投注额的命门，且会跨游戏迁移**：老虎机投注**极度头部集中**（SS03 前 1% 占 ~69%），故总投注额由少数大户主导、波动巨大——**SS03 6-8 月总投注额从 6,402→3,787 万下滑，主因是 6 月头部大户约一半彻底流失、另一半减投并部分迁往 SS01**（10 个 SS03 大户 8 月在 SS01 砸 942 万），与 SS01 8 月投注暴涨（3,895 万）同期。**看游戏健康度要用中位（典型玩家）而非总额/均值**（SS03 典型玩家中位投注 102→113 其实是升的）；大户留存需单独盯。
4. **未见持续正向**：SS02（走弱）、SS06（暗保底小幅提升、后续回落）、SS01（除鲸鱼波动外留存偏低）。
5. **方法学**：本报告是**整体时间轴（描述性）**，规避了 FM01 非随机分组的选择偏差；但整体指标混淆多。**要因果，用老虎机的 user_id 随机分桶**（SS02 AI、SS03 AB、SS06 方案A/B 各 vs 对照）——这些是干净随机 A/B，可另出因果版；FM01 的动态RTP/风控无随机 holdout，因果需研究侧 SageMaker A/B 或匹配/DiD。

## 九、各调控方案的展望 · 计划 · 预估（汇总自各专项文档）

> 以下**逐机制**汇总自各方案专项文档（链接见每节标题），含**已验证效果 / 后续计划 / 预估**。预估为方向性、非承诺。

### 9.1 SS03 数学表 · Fancy Stuff（CBO）　[专项文档](https://bituslabs.atlassian.net/wiki/spaces/hub/pages/1359249416)

- **已验证**：BGTR 系（95bgtr/97bgtr）同期投注 +20~24%、留存不掉，可作后续 default 候选；CBO 训练闭环已跑通。
- **计划（三主线）**：① 建"表特性库"+"表 × 玩家分层（HMM/日龄/投注额）适配矩阵"，作 MAB 选表的先验与冷启动；② **归因并修正实测 RTP vs 理论 RTP 偏差**（拆 BG/FG 实现率、回馈 Esscher 投影层与模拟器校准）；③ **一类玩家一条 RTP 曲线**；④ 生涯曲线 + LTV 监控。
- **预估**：换 CBO 好表转正 default → 参与（投注次数/时长）**+15~20%**。

### 9.2 FM01 动态 RTP v3（分鱼种）　[专项文档](https://bituslabs.atlassian.net/wiki/spaces/hub/pages/1359216831)

- **已验证**：冷启动加成使**新玩家**留存/参与提升（注：strategy 非随机分组、含选择偏差，为相关非因果）。
- **计划（三方向）**：① 机制迭代——调控颗粒度细化到子弹档/鱼值/大鱼组独立曲线；上线**控制软启动、动态历史窗口、动量式目标更新**；② **与个性化挽留系统的兼容与职责划分**（两者都改 rtp_th，需仲裁避免"对着干"）；③ 从短期 RTP 调整**纳入生命周期 / 留存 / LTV** 长期目标。
- **预估**：真实因果需**建随机 holdout** 后才能量化；体量最大（月投注 5-7 亿），+1pp 留存潜在价值最高。

### 9.3 FM01 个性化挽留（一期）　[专项文档](https://bituslabs.atlassian.net/wiki/spaces/hub/pages/1362591745)

- **已验证（全量长期）**：挽留组 9,856 人（+63%）；整组 RTP 97.12% vs default 96.87%（差 <0.4pp，**系统层面不算放水**）；留存 **D1 +1.3pp / D3 +0.15pp**（长期 D7/D10 偏弱）；投注习惯 = **小额·高频·低倍**（投注次数 +13.6%、单笔 −23.6%、投注总额 −13.2%，"打得多花得少"）。
- **计划**：**升级二期**；二期前一期继续基于实测优化**调控力度、参数分布、阶段衔接**；核心理念 = 提高玩家 Tier 间转化率（留存）。
- **预估**：一期方向符合预期但**转化提升空间目前有限**，增益以二期升级为主。

### 9.4 SS03 暗保底（长期全量）　[专项文档](https://bituslabs.atlassian.net/wiki/spaces/hub/pages/1354268688)

- **已验证**：**A 组更均衡安全**（整组消费 +5%、留存基本持平）；**B 组消费拉动最强（+20%）但拿留存换消费**（老玩家留存全线走弱）。拆开看真实触发保底的人：B 组当天消费达 Default **2 倍+**（老玩家 +119%），A 组平淡。**新老玩家是关键分野——新玩家真实触发保底留存全面正向**。
- **计划/方向**：按**新老玩家分策略**（新玩家保底正向、可加强；老玩家 B 组式"猛"保底伤留存需谨慎）。

### 9.5 SS03 AI-MAB 模型　[专项文档](https://bituslabs.atlassian.net/wiki/spaces/hub/pages/1353973761)

- **已验证**：对**高投入用户（1000+）**，AI 轮换**既提升留存也提升收入**（范围1 AI 组人均 GGR ~415 vs 单表 285~320）；同量级下**表组合影响显著**（shi/go 最佳）。
- **计划**：近期 **v4.1 hard-mask 兜底**（mask 新玩家 shi/san、老玩家 Q5 mask ni，让 median bet 往正区间）；每周 self-correction 趋势跟踪（BGTR95_v3 ↑ vs ni ↓）；中期 **v4.2 3-MAB 分层架构**；SS07FG v1 首月监控。
- **预估**：高投入层 AI 选表**收入 + 留存双升**。

### 9.6 SS06 暗保底 v2（proposal）　[专项文档](https://bituslabs.atlassian.net/wiki/spaces/hub/pages/1359184038)

- **v1 发现**：投注金额升但频次降（获大补偿后减少后续投注）；奖池**利用率偏低**（日均 32.5%，前段 39.3→后段 25.9）；A 组实际触发率 17% > 设计 13.84%。
- **计划（v2）**：按**"目标利用率比例"自动调门槛**（降门槛扩覆盖面）；保底参数**按新老玩家标签分别设定**；补偿倍数是否提高留待 v2 在同门槛下按新老分层检验。
- **预估（v1 假设 H1-H4）**：A 组新玩家 bet +17.4%、A 组整体 **D1 12.35% vs Default 8.08%**；**不对留存绝对提升作承诺**（纵向不可比，只用 segmented vs uniform vs holdout 对比）。

### 9.7 综合预估与优先级

| 方向 | 依据（实测） | 预估收益（方向性） | 前提 / 风险 |
|---|---|---|---|
| **AI-MAB 选表推广**（SS02→其他老虎机） | SS02 D1 +2.4pp / 投注 +21%；SS03 高投入层收入+留存双升 | 各游戏留存 +1~2.5pp、投注 +10~20% | 跨游戏可复现；放水略增 |
| **CBO 好表转正 default**（SS03） | TestB 投注 +24% / 次数 +20% | 参与 +15~20% | 持续产好表；价值在表本身 |
| **FM01 建随机 holdout** | 动态RTP/挽留待因果量化 | 体量最大，+1pp 留存价值最高 | 须先建 holdout |
| **挽留升二期 / 暗保底按新老分层** | 挽留 D1 +1.3pp、暗保底新玩家正向 | 转化/留存小幅提升 | 老玩家"猛"保底伤留存需谨慎 |
| **鲸鱼留存专项** | SS03 大户占 69% 投注、流失致总投注 −41% | 留住半数流失大户 ≈ 回补千万级/月 | 鲸鱼波动大 |

**优先级**：① SS02 验证过的 **AI-MAB 推广**到其他老虎机（见效快、风险小）；② SS03 **换 CBO 好表**转正 default；③ FM01 **补随机 holdout**（体量最大、须先能测）；④ **暗保底按新老玩家分层**（SS06 v2、SS03 新玩家正向）；⑤ **鲸鱼留存专项**（投注额最大杠杆）。
